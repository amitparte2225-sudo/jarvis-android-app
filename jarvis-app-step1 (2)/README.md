# JARVIS (Android app)

Personal study, interview and revision companion. Offline-first.

## How to build the app (no installs needed)
1. On GitHub, make a new repository named `jarvis-app` (private is fine).
2. Unzip this folder. Open it. Select everything inside (including the `.github` folder).
3. On the repository page: Add file > Upload files. Drag everything in. Click Commit.
4. Open the **Actions** tab. Wait about 8 to 12 minutes.
5. Green tick = tests passed and the app is built. Red cross = open it, copy the red text, send it to Claude.
6. Open the finished run. At the bottom, under Artifacts, download `jarvis-apk`.
7. Unzip it. Send `app-release.apk` to your phone. Tap it. Allow "install unknown apps" if Android asks.

See docs/ARCHITECTURE.md and docs/CHECKLIST.md.
